# Piekarnia Jedynka

Strona internetowa piekarni Jedynka — zbudowana w [Astro](https://astro.build) i [Tailwind CSS](https://tailwindcss.com), wdrażana na [Cloudflare Workers](https://developers.cloudflare.com/workers/static-assets/) pod domeną [piekarnia-jedynka.pl](https://piekarnia-jedynka.pl).

## Stack

- Astro (statyczny build, bez SSR)
- Tailwind CSS 4
- Cloudflare Workers (static assets) + Wrangler
